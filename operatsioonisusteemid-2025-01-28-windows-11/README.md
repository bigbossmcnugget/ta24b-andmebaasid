# Windows 11 arvuti seadistamine

Jegor Onoprijuk, rühm TA-24B, Operatsioonisüsteemid.

Aruanne: [`Jegor_Onoprijuk_Windows11_seadistamine.pdf`](Jegor_Onoprijuk_Windows11_seadistamine.pdf) (ekraanipildid + lause iga pildi all).
Ekraanipildid on kaustas [`screenshots/`](screenshots).

Tehtud VirtualBoxis (Windows 11 Pro ARM64, arvuti nimi JegorW11): Pro versioon, keel English, Eesti klaviatuur lisatud, lokaalne konto,
11 programmi (Chrome, Opera, Zoom, Discord, VLC, Spotify, Foxit Reader, Dropbox, 7-Zip, TeamViewer, ID-kaardi tarkvara),
tavakasutaja `jegor.onoprijuk` (ei ole administraator), 5 GB FAT32 partitsioon SALAJANE kettatähega X:,
regioonivorming Eesti (kopeeritud lukustuskuvale ja uutele kasutajatele), esmase konto kustutamine.

Mida ei teinud: sisselogimine tavakasutajana ja Adobe Readeri paigaldamise katse.
